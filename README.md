# LanLock

局域网联机保护模组 — 让 Minecraft 局域网联机更安全、更公平。

## 功能

| 功能 | 说明 |
|------|------|
| 🔒 **密码验证** | 非房主玩家首次加入需注册密码，后续登录验证 |
| 🏠 **房主特权** | 房主（开存档的人）自动免验证，可使用创造模式 |
| 🚫 **禁用创造** | 普通玩家无法切换到创造模式，强制生存 |
| 🚫 **禁用 /give** | `/give` 指令对所有非房主玩家无效 |
| 💾 **存档绑定** | 密码随世界存档保存，换世界需重新注册 |

## 使用方法

### 房主（开存档）
1. 安装模组到 `mods` 文件夹
2. 打开局域网世界
3. 自动识别为房主，无需密码，可自由使用创造模式

### 访客（加入者）
- **首次加入**：输入 `/register &lt;密码&gt; &lt;确认密码&gt;` 注册
- **后续加入**：输入 `/login &lt;密码&gt;` 登录
- 密码错误或未登录：无法移动，持续提示

## 安装

将 `lanlock-2.0.0.jar` 放入服务端的 `mods` 文件夹。

**要求：**
- Minecraft 1.21.11
- Fabric Loader &gt;= 0.16.0
- Fabric API

## 命令

| 命令 | 说明 |
|------|------|
| `/register &lt;密码&gt; &lt;确认密码&gt;` | 首次加入时注册 |
| `/login &lt;密码&gt;` | 后续加入时登录 |
